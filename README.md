# Домашнее задание №1 "Анкета пользователя"
## Стандартный функционал
1. **Ввод имени (имеется валидация)**
    
2. **Выбор возраста (слайдер)**
    
3. **Выбор пола (мужской/женский)**
    
4. **Подписка на рассылку (checkbox)**
    
5. **Кнопка "Отправить" (заблокирована при неправильном имени, отображает сводку после нажатия)**

## Дополнительный функционал
1. **Темная и светлая тема**
2. **Корректная альбомная ориентация**
3. **Добавление аватара**
